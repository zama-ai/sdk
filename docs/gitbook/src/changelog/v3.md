# 3.x

Plain-language release notes for the `3.x` line — the current, actively-maintained release line. Here's what changed in each minor version, and why it matters. This complements the auto-generated [`CHANGELOG.md`](https://github.com/zama-ai/sdk/blob/main/CHANGELOG.md) (the full commit-level list) and the [migration guide](../guides/migrate-v2-to-v3.md) (for moving across a major version).

## Versions

- [**3.5.x**](v3-5.md) — Polygon presets, offline signing and decryption permits, at-rest transport-key encryption, and automatic KMS-context recovery.
- [**3.4.x**](v3-4.md) — Release notes for the 3.4.x line.
- [**3.3.x**](v3-3.md) — `confidentialTransferAndCall`, automatic pending-unshield recovery, and typed decryption errors.
- [**3.2.x**](v3-2.md) — configurable, silent-by-default logging; upgrade codemods; and a `Wrap` event decoding fix.
- [**3.1.x**](v3-1.md) — `createConfig`, transport factories, the provider/signer split, the `Token` / `WrappedToken` hierarchy, and top-level FHE primitives.
- [**3.0.x**](v3-0.md) — the first stable v3 line: the high-level clear-text-in, clear-text-out SDK, plus upgraded wrapper and registry contract support.
