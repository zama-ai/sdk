# Daemon deployment

The daemon is a required part of a Go or Rust integration. Run it on your own infrastructure, keep it healthy, and upgrade it safely. Upgrade the daemon image and the clients together, and check [client and daemon compatibility](../reference/client-and-daemon-compatibility.md) before you do.

## Where to go next

🟨 Go to [**Deploy in production**](run-in-production.md) to run the daemon on your infrastructure.

🟨 Go to [**Monitor and troubleshoot**](monitor-and-troubleshoot.md) a running daemon.

🟨 Go to [**Upgrade the daemon**](upgrade-and-recover.md) to replace the daemon and clients together, or roll back.
