# Legacy versions

Release notes for the **superseded** major lines. These are no longer actively developed — the current, actively-maintained release line is [**3.x**](v3.md). To move an app off `1.x` or `2.x`, follow the [migration guide](../guides/migrate-v2-to-v3.md).

## Lines

- [**2.x**](v2.md) — delegated decryption, the wrappers registry, balance validation before transfers, and the public-decrypt primitive.
- [**1.x**](v1.md) — cleartext local development, session-aware signing, wagmi v2 compatibility, and early production hardening.
