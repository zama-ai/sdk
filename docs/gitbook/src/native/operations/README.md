# Daemon deployment

The daemon is a required part of a Go or Rust integration. Run it on your own infrastructure, keep it healthy, and upgrade it safely.

{% hint style="warning" %}
The daemon is experimental. The wire protocol can change between minor versions, so upgrade the daemon image and the clients together — see [client and daemon compatibility](../reference/client-and-daemon-compatibility.md).
{% endhint %}
