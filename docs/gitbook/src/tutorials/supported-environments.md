# Supported environments

| Environment        | Minimum version |
| ------------------ | --------------- |
| Chrome             | 105             |
| Edge               | 105             |
| Android WebView    | 105             |
| Chrome for Android | 105             |
| Safari on iOS      | 15.6            |
| Safari             | 15.6            |
| Firefox            | 115             |
| Samsung Internet   | 20              |
| Node.js            | 22              |

Browser floors apply wherever the SDK runs in a web engine, including embedded WebViews and extension pages.
